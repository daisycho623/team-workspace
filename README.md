# CX 업무 관리 대시보드

Google Sheets `CX` 탭을 읽는 반응형 HTML/CSS/JS 대시보드입니다.

## 로컬 실행

Node.js가 설치된 환경에서 `npm start`를 실행하고 http://127.0.0.1:3000 을 엽니다. 추가 패키지 설치는 필요하지 않습니다. 포트는 `PORT` 환경변수로 바꿀 수 있습니다.

로컬과 배포 환경 모두 동일한 실제 Google Sheets 데이터를 읽습니다. 시트 조회는 Google Visualization의 JSONP 응답을 사용하므로 로컬 출처에서도 읽을 수 있습니다. 시트는 로그인 없이 조회할 수 있도록 공유되어 있어야 합니다.

- 업무: `app.js`의 `ID`에 지정된 스프레드시트의 `CX` 탭
- 작업자: `config.js`에 지정된 Apps Script의 `getWorkers` API. 연결 실패 시 같은 스프레드시트의 `작업자` 탭 A열을 읽습니다(첫 행의 `작업자` 제목 제외).
- 새로고침 버튼: 업무와 작업자 목록을 모두 다시 조회합니다.
- 빈 시트: 연결 성공으로 처리하며 `등록된 업무가 없습니다`를 표시합니다.
- 조회 실패: 연결 오류를 표시하고 이미 화면에 있는 업무는 유지합니다.

기존 업무의 로컬 수정값은 화면에 계속 적용됩니다. 서버 원본을 다시 확인하려면 `수정 초기화`를 누르세요. 새 업무 저장은 기존 Apps Script `appendTask` API를 사용합니다.
